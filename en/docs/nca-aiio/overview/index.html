NCA-AIIO · AI 基础架构与运维

英伟达官方认证页

考试基本信息​

项目详情
考试编号NCA-AIIO
等级Associate（入门级）
考试时长60 分钟
题目数量50 题（每题平均 1.2 分钟）
题型单选题 / 多选题
考试语言英语
考试费用125 美元（部分地区另计税费）
考试形式在线远程监考
证书有效期2 年（可重考续证）

面向人群​

  • 系统管理员、DevOps、网络工程师、IT 经理
  • 数据中心技术人员、解决方案架构师
  • Linux / 嵌入式 / 运维背景

高频易混考点（7 个）​

详见 notes/01-exam-focus-guide

  1. MIG 最多切 7 个（非 8 个），A30 只有 4 个
  2. GPU Operator 管软件部署，HPA 管扩缩容
  3. DCGM 看 GPU，BCM 看集群
  4. DPU 三使命：卸载 / 加速 / 隔离
  5. GDS↔存储 / RDMA↔网卡 / P2P↔GPU — 看清传输端点
  6. H100: 1GbE 给 BMC，10GbE 带内起步，SuperPOD 4 网
  7. 训练重吞吐量，推理重时延（设计侧重，非绝对规则）

考点权重​

模块权重一句话抓总
AI 基础知识38%NVIDIA 软件栈 + 训练推理负载差异 + GPU vs CPU
AI 基础架构40%DGX 拓扑 + 运维 + DPU 贯穿半张卷
AI 运营22%DCGM + 排障 + 虚拟化加速

完整考纲逐条见 exam-objectives.md。

# NCP-AIO · AI 运营中级认证

> NVIDIA-Certified Professional: AI Operations — 中级证书，验证对 NVIDIA AI 基础设施进行监控、故障排除和优化的能力。

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCP-AIO |
| 等级 | Professional（中级） |
| 前置建议 | NCP-AII |
| 考试时长 | 120 分钟 |
| 题型 | 70–75 道选择题 |
| 考试费用 | 2880 元 |
| 证书有效期 | 2 年 |
| [官方考试页面](https://www.nvidia.cn/training/certification/ai-operations-professional/) | ↗ |

## 考试定位

NCP-AIO 认证验证考试者对 NVIDIA AI 基础设施进行**监控、故障排除和优化**的能力。是 NCP-AII（部署管理）的运维进阶。

## 面向人群

- MLOps 工程师
- DevOps 工程师
- 解决方案架构师
- 系统架构师
- AI 基础设施工程师

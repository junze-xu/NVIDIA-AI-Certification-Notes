# NCP-AII · AI 基础设施中级认证

> NVIDIA-Certified Professional: AI Infrastructure — 中级认证，用于验证候选人部署、管理和维护 NVIDIA AI 基础设施的能力。

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCP-AII |
| 等级 | Professional（中级） |
| 前置建议 | NCA-AIIO |
| 考试时长 | 120 分钟 |
| 题型 | 70–75 道选择题 |
| 考试费用 | 2880 元 |
| 证书有效期 | 2 年 |
| [官方考试页面](https://www.nvidia.cn/training/certification/ai-infrastructure-professional/) | ↗ |

## 考试定位

NCP-AII 认证验证候选人**部署、管理和维护 NVIDIA AI 基础设施**的能力。相比 NCA-AIIO 的全局认知，AII 深入到实际部署与运维层面。

## 面向人群

- 数据中心管理员
- 基础设施管理员
- 网络管理员
- 网络工程师
- 存储管理员
- 系统管理员
- 解决方案架构师

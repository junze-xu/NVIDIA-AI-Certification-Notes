# 故障排除与维护 — 速查表

## GPU 故障诊断

| 症状 | 可能原因 |
|------|----------|
| GPU 不可见 | 驱动未安装/版本不匹配 |
| XID 错误 | 硬件/驱动/应用问题 |
| 过热 | 风扇故障/灰尘/气流不足 |
| ECC 错误 | 显存硬件故障 |

## 网络故障

| 症状 | 可能原因 |
|------|----------|
| 链路降速 | 线缆/光模块松动 |
| 丢包 | 网桥配置错误 |
| RDMA 失败 | 驱动/固件不匹配 |

## 日志分析

| 日志 | 内容 |
|------|------|
| `dmesg` | 内核日志 |
| `nvidia-bug-report.sh` | NVIDIA 完整诊断 |
| `journalctl` | 系统日志 |
| DCGM 日志 | GPU 监控告警 |

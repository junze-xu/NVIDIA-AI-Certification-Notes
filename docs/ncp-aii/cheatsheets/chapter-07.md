# 集群管理与监控 — 速查表

## DCGM（Data Center GPU Manager）

| 功能 | 说明 |
|------|------|
| GPU 监控 | 温度、功耗、显存、利用率 |
| 诊断 | 健康检查、故障检测 |
| 策略 | 自动告警、自动响应 |

## 集群监控指标

| 指标 | 说明 |
|------|------|
| GPU 利用率 | 计算利用率百分比 |
| GPU 温度 | 过热告警阈值 |
| 显存使用 | 剩余可用显存 |
| 网络带宽 | 计算和存储网络 |
| 电源功耗 | 机架/节点级 |

## 健康检查流程

1. 硬件状态检查（GPU、内存、磁盘）
2. 网络连通性检查
3. 驱动和容器运行时验证
4. 存储可访问性确认
5. 作业调度器状态

# 机架上架与布线 — 速查表

## 安装顺序（高频考点）

| 步骤 | 操作 |
|------|------|
| 1 | 服务器上架并布线（电源 + 网络） |
| 2 | 安装操作系统（DGX OS 或经验证的 Linux） |
| 3 | 安装基础 NVIDIA 驱动 |
| 4 | 安装容器引擎（Docker/containerd） |
| 5 | 安装 NVIDIA Container Toolkit |
| 6 | 配置运行时 + 重启守护进程 |
| 7 | 认证 NGC：`docker login nvcr.io` |
| 8 | 拉取/测试 GPU 容器，验证 GPU 可见性 |

**考点陷阱：** 把步骤 3-5 顺序颠倒（toolkit 先于驱动/引擎）是经典错误。

---

## 机架与气流

| 要素 | 正确值 |
|------|--------|
| 气流方向 | 前进后出 |
| 冷通道 | 服务器正面（进风） |
| 热通道 | 服务器背面（出风） |
| 规划约束 | 按每机架的电源与制冷预算规划 |

---

## 电源布线

- A/B 双路供电
- 每路 PDU 按 100% 负载配置
- 考虑降额、冗余开销、峰值功耗

# 多节点扩展 — 速查表

## 扩展策略

| 策略 | 工作方式 |
|------|----------|
| 节点内扩展 | NVLink/NVSwitch（最快） |
| 机架内扩展 | InfiniBand/RoCE（快） |
| 跨机架扩展 | 标准以太网（中速） |

## NVLink vs PCIe

| 特性 | NVLink | PCIe |
|------|--------|------|
| 带宽 | 900GB/s（每 GPU） | ~64GB/s（Gen4 x16） |
| 延迟 | 更低 | 更高 |
| 拓扑 | 全互联（NVSwitch） | 树状/网状 |
| 适用 | 节点内 GPU 间 | 主机-设备、跨节点 |

## 扩展考量

| 因素 | 影响 |
|------|------|
| 网络拓扑 | 影响通信效率 |
| 带宽瓶颈 | 限制扩展性 |
| 通信开销 | 随节点数增加 |
| 故障域 | 影响可靠性 |

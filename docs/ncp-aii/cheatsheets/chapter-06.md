# 电源、制冷与链路验证 — 速查表

## 机架电源预算

| 项目 | 关键事实 |
|------|----------|
| DGX H100/H200 最大功耗 | 约 10.2 kW |
| 冗余模型 | A/B 双路供电 — 每路 PDU 按 100% 负载配置 |
| N+1 含义 | 在最低需求（N）之外多一个活动单元 |
| 预算规划 | 考虑降额、冗余开销、峰值瞬时功耗 |

---

## 制冷：风冷 vs 液冷

| 制冷类型 | 使用场景 |
|----------|----------|
| 风冷（CRAC、热/冷通道） | 标准/较低密度机架 |
| 液冷（直触芯片、后门热交换器） | 高密度多 DGX 机架 |
| 常见陷阱 | 增加风扇不能无限扩展 — 高密度下行不通 |

## 链路验证

| 概念 | 说明 |
|------|------|
| BER | 误码率 — 越低越好 |
| 信号眼图 | 评估信号质量 |
| 链路训练 | 自动协商速率和均衡 |

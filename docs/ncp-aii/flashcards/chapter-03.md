# 机架上架与布线 — 知识卡片

## 卡片 1

**Q：正确的 GPU 集群安装顺序？**

A：上架/布线 → OS → 驱动 → 容器引擎 → Container Toolkit → 配置运行时 → NGC 认证 → 测试。

---

## 卡片 2

**Q：机架气流方向？**

A：前进后出。冷通道 = 正面进风，热通道 = 背面出风。

---

## 卡片 3

**Q：电源冗余的 A/B 馈电模型？**

A：每台服务器双电源，分别接入独立 PDU。每个 PDU 必须按独立承载满载选型。

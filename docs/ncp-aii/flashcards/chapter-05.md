# 存储配置 — 知识卡片

## 卡片 1

**Q：AI/ML 工作负载的高性能并行存储选择？**

A：Lustre — HPC、大规模共享、高带宽并行。

---

## 卡片 2

**Q：NVMe 的特点？**

A：极低延迟、本地高性能存储。适合热数据和 checkpoint。

---

## 卡片 3

**Q：S3 对象存储的适用场景？**

A：可扩展、通过 API 访问，适合冷数据/备份/归档。

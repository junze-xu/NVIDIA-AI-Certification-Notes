# NCP-AII AI Infrastructure Professional 考纲逐条要点

## 域 1 · 系统与服务器启动调试（考试权重 31%）

| # | 考点 | 状态 |
|---|---|---|

| 1.5 | 验证电源和散热参数 | ⬜ |
| 1.6 | 安装基于 GPU 的服务器 (nvidia-smi) | ⬜ |
| 1.7 | 验证已安装的硬件 | ⬜ |
| 1.8 | 描述并验证线缆类型和收发器 | ⬜ |
| 1.9 | 安装物理 GPU | ⬜ |
| 1.10 | 验证硬件在工作负载下的运行情况 | ⬜ |
| 1.11 | 配置第三方存储的初始参数 | ⬜ |

NCP-AII 备考：DGX 基础设施 7 个高频易混考点

⚠️ 本文基于官方考纲整理，仅覆盖高频易混考点，不能替代完整考试大纲。

考点 1：DGX H100 vs H200 显存差异​

系统GPU单卡显存GPU 总显存
DGX H1008x H100 SXM580GB HBM3640GB
DGX H2008x H200 SXM5141GB HBM3e1128GB

考试要点：H200 单卡 141GB 是 H100 的 1.76 倍。两者架构相同（NVLink4/NVSwitch），混用允许但需验证。

考点 2：NVLink 带宽代际​

平台每 GPU 带宽NVSwitch 数量
A100 NVLink600 GB/s（双向）6
H100 NVLink900 GB/s（双向）18
Blackwell1800 GB/s（双向）—

考试要点：H100 的 NVSwitch 数量（18）是 A100（6）的 3 倍。

考点 3：电源冗余 N+2 —— 不是 N+1​

项目规格
电源数量6x 3300W
冗余方式N+2（4 个必备 + 2 个备用）
可无影响故障的电源数2 个
系统额定最大功耗约 10.2 kW

考试陷阱：

  • 不要累加电源标称瓦数（6x3300W=19.8kW），实际额定仅 10.2kW
  • N+2 意味着可承受 2 个故障，不是 1 个或 3 个

考点 4：BMC vs nvidia-smi —— 开机前只能用 BMC​

工具何时可用用途
BMC（Redfish/IPMI）开机前带外健康检查，不依赖 OS
nvidia-smiOS 启动后GPU 状态查看
dmesg / systemd journalOS 启动后系统日志

必考规则：开机前健康验证只能用 BMC。nvidia-smi 需要 OS 启动后才能工作。

考点 5：机架预算规则​

按每节点 额定最大功耗（10.2kW） 计算机架负载，不要按电源标称瓦数累加。

正确：10 节点 × 10.2kW = 102kW
错误：10 节点 × 19.8kW = 198kW（高估近一倍）

考点 6：节点内互连拓扑​

项目规格
每块基板 NVSwitch 数4
每 GPU NVLink 带宽900 GB/s（双向）
节点总双向带宽7.2 TB/s（8 × 900 GB/s）

考试要点：DGX 节点总带宽 = GPU 数 × 每 GPU 带宽。

考点 7：H100/H200 混用规则​

H100 和 H200 混用在同一 NVLink 域中是可行的，但需要：

  • 验证兼容性
  • 固件/驱动版本一致
  • BMC 固件版本统一

考试陷阱：混用不是"完全禁止"，而是"允许但需验证"。

速记总表​

一句话考点答案

H100 NVLink 带宽？900 GB/s

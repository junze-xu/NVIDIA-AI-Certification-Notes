# 第 3 章 — 知识卡片

## 卡片 1

**Q：Supervisor/worker 模式的定义特征？**

中央agent路由并委派给专家worker，专家仅向中央汇报，互不通信。考试:中央路由+无横向通信=Supervisor。

## 卡片 2

**Q：分层多智能体树的场景？**

多级manager委派，中层管下层。法律工作流:领域manager→专门worker。考试:多级管理=分层树。

# 第 1 章 — 知识卡片

## 卡片 1

**Q：ReAct 与 Plan-and-execute 的核心区别？**

ReAct 基于观察动态分支（Thought+Action+Observation); Plan-and-execute 预先承诺完整计划后顺序执行。考试:动态分支选ReAct。

---

## 卡片 2

**Q：何时使用 Tree-of-thought？**

多解路径、需回溯的逻辑谜题。ToT 显式生成多分支、评分、允许回溯死胡同。考试:多路径+回溯=ToT。

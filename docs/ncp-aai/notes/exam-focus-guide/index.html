NCP-AAI 备考：智能体 AI 7 个高频易混考点

⚠️ 本文基于官方考纲整理，仅覆盖高频易混考点，不能替代完整考试大纲。

考点 1：四阶段智能体循环​

阶段发生什么常见混淆
感知摄取输入/观察（查询、工具输出、环境状态）易与行动混淆
推理基于当前状态和目标决定下一步易与反思混淆
行动执行工具调用或产出输出—
反思评估动作与目标差距；修正方法易与推理混淆

考试要点：推理是"决定做什么"，反思是"评估做得怎样"。两者不同！

考点 2：控制模式选择指南​

模式最适用考试触发语
ReAct下一步依赖实时结果"结果决定下一动作"、"先查 X 再决定"
Plan-and-execute步骤已知、可预测"理解透彻的工作流"、"步骤事先已知"
CoT单一线性推理默认推理，无分支
ToT需探索多个候选解"探索多种方法"、"比较备选"

考点 3：单智能体 vs 多智能体决策​

信号选择
范围窄、工具少、一个知识库单智能体
需要并行工作的不同专门角色多智能体
冲突子目标需协商多智能体
上下文/工具集超出单窗口多智能体

考点 4：确定性边界 vs 自主区​

概念说明考试触发语
确定性边界特定高风险动作的硬编码门限（人工审批、白名单）"X 之前必须获得审批"
自主区智能体无需门限即可执行的动作内部消息、只读查询

考试要点：确定性边界仅限定特定动作，不意味着完全丧失自主性。

考点 5：系统提示设计铁律​

  1. 显式陈述安全和工具使用约束
  2. 让约束优先于角色/语气指令
  3. 角色塑造语气/风格，绝不能允许它覆盖硬性规则

考试陷阱：安全约束必须放在 prompt 前面，不能埋在背景故事之后。

考点 6：自反思风险 —— 无限循环​

无界自反思可能导致：

  • 无限循环
  • 浪费延迟/成本
  • 无质量保证

修复方法：限制迭代次数（较小的固定值）或使用显式的收敛/质量检查。

考点 7：快速决策清单​

下一步依赖实时结果？ → ReAct
步骤完全事先已知？ → Plan-and-execute
需探索/比较多路径？ → ToT
任务窄 + 工具少？ → 单智能体
高风险动作？ → 加确定性审批门

速记总表​

一句话考点答案

# 工具集成、API 与模型上下文协议 — 速查表

## 安全重试

| 技术 | 作用 | 防止 |
|------|------|------|
| 幂等键 | 同键重试返回原结果 | 重复执行副作用（双订单） |
| 指数退避 | 间隔递增重试 | 服务端过载 |

## 代码执行安全

| 措施 | 说明 |
|------|------|
| 隔离沙箱 | 容器/受限环境 |
| 受限文件系统 | 最小文件访问 |
| 受限网络访问 | 禁止外部通信 |

:::info 记忆锚点
防双执行→幂等键；代码安全→隔离沙箱+受限FS/网络
:::

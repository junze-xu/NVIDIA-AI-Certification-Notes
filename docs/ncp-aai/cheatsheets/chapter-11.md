# 护栏、安全与负责任部署 — 速查表

## 间接 Prompt Injection

| 攻击 | 正确防御 |
|------|----------|
| 工具输出含隐藏指令（邮件转发给 attacker）| 执行 rail，把检索内容当数据，高风险工具调用前策略校验/人工审批 |

## 风险分级监督

| 操作风险 | 监督级别 |
|----------|----------|
| 读取账户余额 | 自主执行 |
| 电汇 $50,000 | 需人工审批 |

:::info 记忆锚点
间接注入→执行rail+工具输出当不可信数据；高风险操作→人工审批
:::

# 任务分解与记忆系统 — 速查表

## 记忆类型

| 类型 | 内容 | 场景 |
|------|------|------|
| 短期/工作记忆 | 当前会话上下文 | 即时推理 |
| 情景记忆 | 特定过去交互（3周前用户偏好）| 个性化服务 |
| 语义记忆 | 事实知识（巴黎是法国首都） | 知识检索 |
| Scratchpad/目标重述 | 每步重申原始目标 | 长视野任务防漂移 |

## 长任务防漂移技术

| 问题 | 解决方案 |
|------|----------|
| 40 步任务偏离原始目标 | 每步重新注入目标陈述 |
| 跨会话个性化 | 情景记忆存储用户偏好 |

:::info 记忆锚点
目标漂移→每步重述；特定过去→情景记忆；事实知识→语义记忆
:::

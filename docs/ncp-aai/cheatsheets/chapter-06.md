# 面向智能体的检索增强生成 — 速查表

## 核心模式

| 步骤 | 操作 | 目的 |
|------|------|------|
| 分块 | 300-500 token/块 | 适合嵌入+检索 |
| 嵌入 | 向量表示 | 语义搜索 |
| 检索 | Top-k 相关块 | 候选获取 |
| 重排 | 交叉编码器精排 | 提升相关性 |
| 生成 | LLM 产出答案 | 引用源块 |

## 混合检索

| 方法 | 优势 |
|------|------|
| BM25/关键词 | 精确 ID 查找（"第 12.4(b) 节"） |
| 稠密嵌入 | 语义概念匹配 |
| 混合（BM25+稠密+重排） | 两者兼顾 |

:::info 记忆锚点
分块300-500；精确ID→BM25；语义→嵌入；最佳→混合+重排
:::

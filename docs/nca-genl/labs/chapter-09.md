# 实验：真实世界 LLM 应用

:::note 预计用时
12 分钟
:::

## 实验目标

- 能根据用例选择合适大小的模型
- 理解批处理策略的取舍
- 掌握延迟 vs 吞吐 vs 质量的权衡

## 练习 1：模型选择决策

| 用例 | 推荐模型大小 | 原因 |
|------|-------------|------|
| 文本分类/抽取 | 1.3B（蒸馏） | 低延迟、低成本 |
| 通用任务 | 7B | 平衡 |
| 复杂推理 | 13B+ | 高质量 |

## 练习 2：批处理策略

```python
# 动态批处理 — 在线请求组合
# 连续批处理 — 不定长请求最大 GPU 利用率
# 静态批处理 — 离线固定 batch
```

:::caution
模型越大 → 延迟更高、吞吐更低、质量更高。根据 SLA 权衡。
:::

## 关键要点

:::info 本章记忆锚点
分类用小模型（1.3B），通用用 7B，推理用 13B+。动态批处理提高在线吞吐。
:::

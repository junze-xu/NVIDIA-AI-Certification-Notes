# LLM 集成与部署 — 知识卡片

## 卡片 1

**Q：RAG 架构的正确流程？**

A：查询 → 嵌入 → 向量搜索 → 检索 Top-K 块 → 注入提示 → LLM 生成。

---

## 卡片 2

**Q：低于 500 个训练示例时，默认选择什么方案？**

A：**提示工程 / RAG** — 微调需要超过 1000 标注示例才能有效。

---

## 卡片 3

**Q：FAISS 和 Milvus 的区别是什么？**

A：
- FAISS：本地库，适合原型（低于 1000 万向量）
- Milvus：自托管，适合大规模生产

---

## 卡片 4

**Q：什么时候应该选择微调而不是 RAG？**

A：需要永久改变风格/格式/领域，且有超过 1000 标注示例时。动态知识/新鲜度需求选 RAG。

# 真实世界 LLM 应用架构 — 知识卡片

## 卡片 1

**Q：7B 模型在单块 A100 上的内存占用？**

A：约 14GB。1.3B 约 3GB，13B 约 26GB。

---

## 卡片 2

**Q：动态批处理和连续批处理的区别？**

A：
- 动态批处理：在线请求组合成 batch
- 连续批处理：不定长请求最大化 GPU 利用率

---

## 卡片 3

**Q：模型大小增加对延迟和吞吐的影响？**

A：模型越大 → 延迟更高、吞吐更低、质量更高。需根据用例权衡。

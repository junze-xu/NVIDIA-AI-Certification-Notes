# NCA-ADS 考纲逐条要点

> 来源：英伟达官方考试页面 · [Accelerated Data Science Associate](https://www.nvidia.cn/training/certification/accelerated-data-science-associate/)
>
> ⚠️ 版权归 NVIDIA 所有；本仓只整理覆盖度清单，不含 PDF 副本。

## 域 1 · 数据处理和准备（考试权重 23%）

| # | 考点 | 状态 |
|---|---|---|
| 1.1 | 使用 NVIDIA cuDF 和 pandas 进行数据集成、连接和处理 | ⬜ |
| 1.2 | 数据清洗、质量处理和数据治理合规 | ⬜ |
| 1.3 | 使用 RAPIDS、Dask 或 Spark 构建 GPU 加速的 ETL 工作流 | ⬜ |
| 1.4 | 数值变量和类别变量的特征工程 | ⬜ |
| 1.5 | 处理类别不平衡并生成合成数据 | ⬜ |
| 1.6 | 降维和数据采样 | ⬜ |
| 1.7 | 使用 Parquet 和现代框架实现高效数据处理和存储 | ⬜ |

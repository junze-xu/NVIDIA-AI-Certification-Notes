# NCA-ADS · 加速数据科学 RAPIDS

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCA-ADS |
| 考试时长 | 60 分钟 · 50–60 道选择题 |
| 考试费用 | 960 元 |
| 证书有效期 | 2 年 |

> ⚠️ 本门考试**无官方中文版学习指南**，仅有英文版 Study Guide。

## 考点权重

| 模块 | 权重 |
|---|---|
| 数据处理与准备 | 23% |
| 机器学习（RAPIDS） | 16% |
| 数据科学流水线自动化 | 13% |
| 描述性分析 & 可视化 | 13% |
| 加速数据科学基础 | 12% |
| MLOps 实践入门 | 10% |
| 高级数据结构 | 7% |
| 软件 & 环境管理 | 6% |

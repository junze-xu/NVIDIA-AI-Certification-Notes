# NCA-ADS · Accelerated Data Science Associate

> [英伟达官方认证页](https://www.nvidia.cn/training/certification/accelerated-data-science-associate/)

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCA-ADS |
| 等级 | Associate（初级） |
| 考试时长 | 约 1 小时 |
| 题型 | 单选题 / 多选题 |
| 语言 | 中文 |
| 考试费用 | 见官网 |
| 证书有效期 | 2 年 |

## 面向人群

- 数据科学家、数据分析师
- 使用 GPU 加速数据科学工作流的开发者

## 考点权重

| 模块 | 权重 | 一句话抓总 |
|---|---|---|
| 数据处理和准备 | 23% | cuDF + RAPIDS + ETL + 特征工程 |
| 使用 RAPIDS 进行机器学习 | 16% | cuML + XGBoost + 模型评估 |
| 数据科学工作流和流程自动化 | 13% | 端到端工作流 + Dask 流水线 |
| 描述性分析和可视化 | 13% | EDA + 可视化 + 假设检验 |
| 加速数据科学基础 | 12% | NumPy/pandas + GPU 基础 |
| MLOps 入门实践 | 10% | 实验跟踪 + 部署 + 监控 |
| 高级数据结构 | 7% | 时间序列 + 图数据 |
| 软件和环境管理 | 6% | Conda/Docker + GPU 环境检查 + git |

> 完整考纲逐条见 [exam-objectives.md](./exam-objectives.md)。

I/O 与 GPU 流水线 — 速查表

文件格式吞吐对比​

格式布局列裁剪谓词下推GPU 读取速度
CSV行否否最慢
Parquet列式是是快，窄投影最佳
ORC列式是是与 Parquet 相当
提示

查询触及不到 50% 列时，列式格式大幅胜出。CSV 不支持下推。

下推语法​

# Parquet 列 + 谓词下推
cudf.read_parquet(path, columns=['id','amount'], filters=[('amount','>',1000)])

# ORC stripe + 列裁剪
cudf.read_orc(path, columns=['id','amount'], stripes=[0,1])

在 read_parquet() 之后再过滤 ≠ 谓词下推，浪费 I/O。

压缩编解码权衡​

编解码解码速度压缩比适用场景
Snappy最快较低吞吐关键、频繁热读
LZ4很快较低低延迟流水线
GZIP较慢较高存储敏感、不频繁读
ZSTD中—慢高平衡比/速度

执行模型选择​

场景选择
装入单 GPU 内存单 GPU cuDF
超出单 GPU，装入节点多 GPUDask-cuDF
已有 Spark SQL/DataFrame 任务Spark RAPIDS Accelerator
大规模 ML 训练/推理cuML / cuGraph
警告

Spark RAPIDS ≠ 用 cuDF 重写任务 — 关键是"无代码重写"。

监控信号​

信号瓶颈类型修复方向
低 GPU 利用率 + 长读取等待I/O 受限格式/下推/压缩
持续高 GPU 利用率计算受限内核/算法/批大小

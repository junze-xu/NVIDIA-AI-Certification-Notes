考试基本信息​

项目详情
考试编号NCA-ADS
等级Associate（初级）
考试时长约 1 小时
题型单选题 / 多选题
语言中文
考试费用见官网
证书有效期2 年

面向人群​

  • 数据科学家、数据分析师
  • 使用 GPU 加速数据科学工作流的开发者

考点权重​

模块权重一句话抓总
数据处理和准备23%cuDF + RAPIDS + ETL + 特征工程
使用 RAPIDS 进行机器学习16%cuML + XGBoost + 模型评估
数据科学工作流和流程自动化13%端到端工作流 + Dask 流水线
描述性分析和可视化13%EDA + 可视化 + 假设检验
加速数据科学基础12%NumPy/pandas + GPU 基础
MLOps 入门实践10%实验跟踪 + 部署 + 监控
高级数据结构7%时间序列 + 图数据
软件和环境管理6%Conda/Docker + GPU 环境检查 + git

# NCA-AIIO 考纲逐条要点

## 域 1 · AI 基础知识（考试权重 38%）

| # | 考点 | 状态 |
|---|---|---|
| 1.1 | 描述 AI 环境中使用的 NVIDIA 软件栈 | ⬜ |
| 1.2 | 比较并对比训练与推理架构的需求与注意事项 | ⬜ |
| 1.3 | 区分 AI、机器学习与深度学习的概念 | ⬜ |
| 1.4 | 解释 AI 快速发展与应用普及的成因 | ⬜ |
| 1.5 | 说明 AI 的主要应用场景与相关行业用例 | ⬜ |
| 1.6 | 说明各类 NVIDIA 解决方案的用途与应用场景 | ⬜ |
| 1.7 | 描述与 AI 开发和部署生命周期相关的软件组成部分 | ⬜ |
| 1.8 | 比较并对比 GPU 与 CPU 架构 | ⬜ |

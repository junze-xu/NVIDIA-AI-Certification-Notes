# NCP-ADS Accelerated Data Science Professional 考纲逐条要点

> 来源：英伟达官方考试页面 · [Accelerated Data Science Professional](https://www.nvidia.cn/training/certification/accelerated-data-science-professional/)
>
> ⚠️ 版权归 NVIDIA 所有；本仓只整理覆盖度清单，不含 PDF 副本。

## 域 1 · 数据分析（考试权重 14%）

| # | 考点 | 状态 |
|---|---|---|
| 1.1 | 检测时间序列数据集中的异常 | ⬜ |
| 1.2 | 进行时间序列分析 | ⬜ |
| 1.3 | 使用 cuGraph 等工具创建和分析图形数据 | ⬜ |
| 1.4 | 确定大数据的数据量，或加速的时间和方式 | ⬜ |
| 1.5 | 执行探索性数据分析 (EDA) | ⬜ |
| 1.6 | 时间序列数据可视化 | ⬜ |

## 域 2 · 数据操作和软件专业知识（考试权重 19%）

| # | 考点 | 状态 |
|---|---|---|
| 2.1 | 采用加速 ETL 流程来设计和实施 ETL 工作流 | ⬜ |
| 2.2 | 实施数据缓存以减少混洗 | ⬜ |
| 2.3 | 使用分布式数据处理框架处理大数据 | ⬜ |
| 2.4 | 使用 Dask 实施数据并行以实现多 GPU 扩展 | ⬜ |
| 2.5 | 使用 DLProf 等工具对深度学习模型进行分析 | ⬜ |
| 2.6 | 确定不同规模的数据集的最佳数据处理库 | ⬜ |

## 域 3 · 数据准备（考试权重 17%）

| # | 考点 | 状态 |
|---|---|---|
| 3.1 | 使用 CuDF 和 pandas 执行数据清理和预处理 | ⬜ |
| 3.2 | 对数据进行转换和标准化处理 | ⬜ |
| 3.3 | 按需对数据进行标准化处理，确保各项功能的一致性 | ⬜ |
| 3.4 | 使用 cuDF 和 NVIDIA RAPIDS™ 生成合成数据增强数据集 | ⬜ |
| 3.5 | 识别和获取数据集 | ⬜ |
| 3.6 | 监控数据处理工作流并识别瓶颈 | ⬜ |
| 3.7 | 处理、组织和存储数据集 | ⬜ |

| # | 考点 | 状态 |
|---|---|---|

| 4.3 | 描述、遵循和执行 CRISP-DM 流程 | ⬜ |

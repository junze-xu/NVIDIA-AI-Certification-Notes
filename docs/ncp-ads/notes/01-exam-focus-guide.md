# NCP-ADS 备考：专业级加速数据科学 7 个高频易混考点

> ⚠️ 本文基于官方考纲整理，仅覆盖高频易混考点，**不能替代完整考试大纲**。
> NCP-ADS 是专业级（Professional），比 NCA-ADS 更深入 CUDA 架构与系统集成层。

## 考点 1：warp = 32 个线程 —— SIMT 执行的最小单位

GPU 线程层级：

| 层级 | 说明 | 考试要点 |
|---|---|---|
| **CUDA Core** | 每周期执行一个线程的指令 | 基础计算单元 |
| **Warp** | **32 个线程**同步执行（SIMT） | 务必记住 = 32 |
| **SM** | 调度 warp，含多个 CUDA 核心 + 共享内存 | H100 ≈ 132 个 SM |
| **GPU** | SM 阵列 | — |

**考试陷阱**：warp 内的分支分歧（divergent branch）会**强制串行化**执行路径——常见性能坑。

## 考点 2：cuGraph vs cuSpatial —— "相连"数据但领域不同

| 库 | 领域 | 用例 |
|---|---|---|
| **cuGraph** | 网络/图 | 最短路径、PageRank、社区发现 |
| **cuSpatial** | 地理/位置 | 地理信息、空间查询、轨迹分析 |

**考试陷阱**：两者都处理"相连"数据，但 cuGraph 处理图网络，cuSpatial 处理地理/空间数据。

## 考点 3：CPU vs GPU 设计哲学

| | CPU | GPU |
|---|---|---|
| 优化目标 | 延迟 | 吞吐 |
| 执行模型 | MIMD | SIMT |
| 核心数 | 少（4-64+） | 数千 |
| 核心复杂度 | 复杂、乱序 | 简单、顺序 |

## 考点 4：互连带宽数量级

| 链路 | 近似带宽 |
|---|---|
| PCIe Gen4 x16 | ~32 GB/s 单向 |
| PCIe Gen5 x16 | ~64 GB/s 单向 |
| NVLink 3（A100） | ~600 GB/s 每 GPU |
| NVLink 4（H100） | ~900 GB/s 每 GPU |

**考试陷阱**：主机到设备（H2D）传输走 **PCIe**。NVLink 仅加速 GPU 间通信，不加速主机到 GPU。

## 考点 5：Amdahl 定律 —— 串行部分封顶加速比

**加速比 = 1 / ((1-P) + P/S)**

- P = 可并行部分占比
- S = 并行部分的加速比
- 串行部分即便 GPU 无限快也会封顶总加速比

## 考点 6：RAPIDS CUDA-X 栈自底向上

| 层 | 用途 |
|---|---|
| CUDA | 低层并行计算平台 |
| cuDF | GPU DataFrame |
| cuML | GPU 机器学习 |
| cuGraph | GPU 图分析 |
| cuSpatial | GPU 地理空间分析 |

## 考点 7：内存管理关键规则

- 主机 RAM 与 GPU VRAM 是**分离的地址空间**
- 数据须在计算前显式拷贝 H2D、计算后 D2H
- 多次小传输比一次大传输更贵（每传输有固定延迟开销）

**考试要点**：统一内存和 GPUDirect Storage/RDMA 可以规避显式拷贝。

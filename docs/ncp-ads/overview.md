# NCP-ADS · Accelerated Data Science Professional

> [英伟达官方认证页](https://www.nvidia.cn/training/certification/accelerated-data-science-professional/)

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCP-ADS |
| 等级 | Professional（专业级） |
| 考试时长 | 约 1 小时 |
| 题型 | 单选题 / 多选题 |
| 语言 | 中文 |
| 考试费用 | 见官网 |
| 证书有效期 | 见官网 |

## 面向人群

- 数据科学家、数据分析师、ML 平台工程师
- 使用 GPU 加速工作流的开发者

## 考点权重

| 模块 | 权重 | 一句话抓总 |
|---|---|---|
| 数据分析 | 14% | 异常检测 + 时间序列 + cuGraph |
| 数据操作和软件专业知识 | 19% | ETL + Dask + DLProf |
| 数据准备 | 17% | cuDF/pandas + RAPIDS |
| GPU 和云计算 | 16% | GPU 加速 + CRISP-DM + Docker/Conda |
| 机器学习 | 15% | 特征工程 + 训练 + 混合精度 |
| MLOps | 19% | 基准测试 + 部署 + 监控 |

> 完整考纲逐条见 [exam-objectives.md](./exam-objectives.md)。

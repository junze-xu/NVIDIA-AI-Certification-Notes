# 实验：数据集整理

:::note 预计用时 15 分钟 :::

## 练习 1：去重方法
| 场景 | 方法 | 原理 |
|------|------|------|
| 大规模近似去重(85%相似) | MinHash + LSH | 近似 Jaccard，同桶比较 |
| 精确去重 | SHA-256 哈希 | 字节级相同 |

## 练习 2：LSH band 数增加效果
band 更多 + 每 band 行数更少 → 召回率上升、精确率下降

## 练习 3：灾难性遗忘
微调数据混合中代码几乎为 0 → 预训练学到的编码能力退化

:::info 记忆锚点
MinHash+LSH=近似去重；格式统一=微调前提；分布失衡=灾难性遗忘
:::

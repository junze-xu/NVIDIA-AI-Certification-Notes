# 实验：推理加速量化

:::note 预计用时 15 分钟 :::

## 练习 1：量化方法选择
| 场景 | 最佳方法 | 原因 |
|------|----------|------|
| 内存受限 70B | AWQ INT4 | 接近 FP16 精度，内存 1/4 |
| H100 GPU | FP8 | 硬件原生，最高吞吐 |
| 精度敏感 | FP16/FP8 | 避免量化损失 |

## 练习 2：投机解码原理
小模型 draft 猜多个 token → 大模型并行验证 → 单步多 token → 2-3x 加速

:::info 记忆锚点
AWQ=激活感知保护；FP8=H100原生；投机=小猜大验
:::

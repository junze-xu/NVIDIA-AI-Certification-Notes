# 实验：分布式训练并行策略

:::note 预计用时 20 分钟 :::

## 练习 1：选择策略
| 场景 | 首选 | 原因 |
|------|------|------|
| 单层过大装不下 | 张量并行 | 切权重矩阵 |
| 模型能放下要加速 | 数据并行 | 复制模型分数据 |
| 节点内 8 GPU | TP | NVLink 高带宽 |
| 长序列 64K+ | 序列并行 | 切激活序列维度 |

## 练习 2：张量并行限制
不能跨节点——需要节点内 NVLink 900GB/s 带宽

## 练习 3：组合方案
64 GPU 4 节点：TP(8, 节点内) + PP(跨节点) + DDP

:::info 记忆锚点
大单层→TP；能放下→DDP；节点内→TP；长序列→SP
:::

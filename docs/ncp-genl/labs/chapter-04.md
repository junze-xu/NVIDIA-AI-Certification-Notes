# 实验：适配策略决策

:::note 预计用时 20 分钟 :::

## 练习 1：策略选择
| 场景 | 最佳策略 | 原因 |
|------|----------|------|
| 每日更新内部文档 | RAG | 知识时效性与模型解耦 |
| 严格品牌口吻+低延迟 | 微调 | 行为模式固化进权重 |
| 20 条静态 FAQ | 直接放提示 | 无需基础设施 |
| 超出上下文的大语料 | RAG | 分块检索 |

## 练习 2：RAG 组件
分块器 → 嵌入模型 → 向量存储 → 检索器 → 重排序器 → 生成器

## 练习 3：分块过大后果
主题混杂 → 稀释相关性信号 → 检索精确度下降 + 可能超出上下文

:::info 记忆锚点
动态知识→RAG；风格固化→微调；小静态→直接提示
:::

# 全真模拟与策略 — 速查表

## 考试参数

| 项目 | 数值 |
|------|------|
| 考试时长 | 120 分钟 |
| 题目数量 | 70-75 道选择题 |
| 考试费用 | 2880 元 |
| 前置建议 | NCP-AII 或 NCA-AIIO |

## 时间分配策略

| 策略 | 说明 |
|------|------|
| 首轮节奏 | 按总时间 ÷ 题数计算每题预算 |
| 标记机制 | 超过 2 分钟标记后继续 |
| 复查缓冲 | 预留 10-15 分钟复查标记题 |
| 示例 | (120 - 15) ÷ 70 ≈ 每题 1.5 分钟 |

## 答题最佳实践

| 策略 | 说明 |
|------|------|
| 先猜后标记 | 即使不确定也选最佳猜测 + 标记 |
| 排除法 | 先排除明显错误/已弃用产品的干扰项 |
| 不留空 | 无惩罚，始终作答 |
| 加权复习 | 优先复习高权重 + 低分数 Domain |

AR/PCC 与 IB vs Spectrum-X 权衡 — 速查表

静态 ECMP 的 AI 流量问题​

问题原因
部分链路拥塞、部分闲置少数超大 elephant flow 哈希冲突
AI 流量特点少量极大、长生命周期的流（all-reduce）
企业 Web 流量特点大量小型多样流 → ECMP 统计分布良好

Spectrum-X vs 静态 ECMP 方案​

方案机制
自适应路由（AR）按报文喷洒到多条实时可用路径
可编程拥塞控制（PCC）摄取交换机/DPU 遥测 → 微秒级调整发送速率

IB vs Spectrum-X 权衡矩阵​

因素选择 InfiniBand选择 Spectrum-X
性能要求极致最低延迟接近 IB 的性能
租户模式单租户多租户
团队技能有子网管理经验以太网/IP 工程师
网内计算需要 SHARP无等效需求
隔离机制pkeyVXLAN/EVPN

PCC 与传统 DCQCN 对比​

维度DCQCNPCC
信号来源仅主机端 ECN 标记交换机/DPU 实时遥测
收敛速度较慢微秒级
尾延迟控制一般优秀

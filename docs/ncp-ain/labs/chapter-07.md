# 实验：无损以太网调优

:::note 预计用时
20 分钟
:::

## 实验目标

- 理解 PFC 与全局暂停的粒度差异
- 掌握 ECN 码点含义
- 理解 DCQCN 三角色交互

## 练习 1：PFC vs 全局暂停

| 需求 | 机制 | 原因 |
|------|------|------|
| 只暂停 RDMA 队列，不影响 TCP | PFC (802.1Qbb) | 按优先级粒度的队列暂停 |
| 停止整条物理链路的所有流量 | 802.3x 全局暂停 | 无差别暂停 |

## 练习 2：ECN 码点识别

| 码点 | 含义 |
|------|------|
| 00 | Not-ECT（不支持 ECN） |
| 01 | ECT(0)（支持，可标记） |
| 10 | ECT(1)（支持，可标记） |
| **11** | **CE（拥塞经历）** |

## 练习 3：DCQCN 交互流程

```text
交换机(CP) → ECN 标记报文 → 接收方(NP)
                                      ↓
发送方(RP) ← 降低速率 ← 生成 CNP ←┘
```

| 角色 | 位置 | 职责 |
|------|------|------|
| CP | 交换机 | 拥塞时 ECN 标记 |
| NP | 接收方 | 收到标记后生成 CNP |
| RP | 发送方 NIC | 收到 CNP 后降速 |

## 练习 4：PFC 死锁缓解

级联暂停跨多跳传播 → **PFC watchdog**：检测异常长暂停端口并临时禁用 PFC 以打破风暴。

## 关键要点

:::info 本章记忆锚点
PFC 按队列暂停（精细）。ECN CE = 拥塞信号（码点 11）。DCQCN：CP标记→NP生成CNP→RP降速。
:::

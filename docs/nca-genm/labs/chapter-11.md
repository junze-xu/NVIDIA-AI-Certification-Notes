# 实验：多模态应用

:::note 预计用时
10 分钟
:::

## 实验目标

- 了解多模态 RAG 架构
- 掌握真实世界应用案例
- 理解部署权衡

## 练习 1：多模态 RAG 流程

```
查询（文本/图像）→ 多模态嵌入 → 向量搜索 → 检索上下文 → VLM 生成
```

## 练习 2：应用匹配

| 应用 | 模态 |
|------|------|
| 医学影像 | 图像 + 文本 |
| 自动驾驶 | 摄像头 + 激光雷达 |
| 内容生成 | 文本 → 图像/视频 |

## 关键要点

:::info 本章记忆锚点
多模态 RAG 使用 VLM 处理文本+图像。部署需权衡延迟、吞吐、成本、质量。
:::

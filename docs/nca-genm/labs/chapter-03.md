# 实验：实验设计

:::note 预计用时
12 分钟
:::

## 实验目标

- 掌握多模态数据划分原则
- 能选择调优方法
- 理解数据泄漏风险

## 练习 1：数据划分

```python
# 正确：按唯一实体划分
train_ids = unique_entities[:70%]
test_ids = unique_entities[70%:]

# 错误：按片段划分（同一视频片段进入训练和测试）
# 这会导致数据泄漏！
```

## 练习 2：调优方法选择

| 场景 | 方法 |
|------|------|
| 1-2 个超参数 | 网格搜索 |
| 多超参数、算力有限 | 随机搜索 |
| 样本效率优先 | 贝叶斯优化 |

## 关键要点

:::info 本章记忆锚点
按唯一实体划分防泄漏。超参数多选随机搜索或贝叶斯。
:::

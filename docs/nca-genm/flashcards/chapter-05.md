# 多模态模型 — 知识卡片

## 卡片 1

**Q：CLIP 如何实现零样本图像分类？**

A：用文本描述类别，通过对比学习匹配图像和文本嵌入。

## 卡片 2

**Q：视觉语言模型的早期融合和晚期融合的区别？**

A：早期在输入层合并模态，晚期在输出层合并。

**Q：BLIP 的主要能力？**

# 多模态模型 — 速查表

## CLIP（对比语言-图像预训练）

| 组件 | 作用 |
|------|------|
| 图像编码器 | 将图像编码为嵌入 |
| 文本编码器 | 将文本编码为嵌入 |
| 对比学习 | 匹配图像-文本对推近，不匹配推远 |

**考试要点：** CLIP 实现零样本图像分类 — 用文本描述类别即可分类。

---

## 多模态融合策略

| 策略 | 工作方式 |
|------|----------|
| 早期融合 | 在输入层合并模态 |
| 晚期融合 | 分别处理，在输出层合并 |
| 中间融合 | 在中间层交互 |

---

## 视觉语言模型

| 模型 | 特点 |
|------|------|
| CLIP | 对比学习，零样本分类 |
| BLIP | 图像字幕 + 理解 |
| Flamingo | 上下文学习，少样本 |
| LLaVA | 视觉指令微调 |
| GPT-4V | 多模态理解 + 生成 |

---

## 多模态应用

| 应用 | 输入 | 输出 |
|------|------|------|
| 图像描述 | 图像 | 文本 |
| VQA | 图像 + 问题 | 答案 |
| 文本到图像 | 文本 | 图像 |
| 图像到文本 | 图像 | 描述 |

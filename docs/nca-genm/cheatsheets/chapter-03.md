# 实验设计与提示工程 — 速查表

## 训练/验证/测试集划分（多模态）

| 实践 | 经验法则 |
|------|----------|
| 比例 | 70/15/15 或 80/10/10 |
| 泄漏风险 | 按唯一实体（视频/患者/会话 ID）划分 |
| 分层抽样 | 保持类别/标签均衡 |
| 多模态配对 | 配对的模态必须在同一划分中 |

**易错点：** 将同一源视频的片段随机划分到训练/测试集 = 数据泄漏。

---

## 超参数调优

| 方法 | 适用场景 |
|------|----------|
| 网格搜索 | 超参数少（1-2 个）、搜索空间小 |
| 随机搜索 | 超参数多、算力有限 |
| 贝叶斯优化 | 样本效率最高；利用先前运行结果指导搜索 |

**关键超参数：**
- **学习率：** 过高 → 损失发散/NaN；过低 → 收敛慢/欠拟合
- **批量大小：** 更大 → 梯度更平滑，但需按比例调高 LR

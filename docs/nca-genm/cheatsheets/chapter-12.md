# 考试策略模拟 — 速查表

## 考试格式

| 参数 | 值 |
|------|-----|
| 题数 | 50-60 道多选题 |
| 时长 | 60 分钟 |
| 每题预算 | 60-70 秒 |
| 标记阈值 | 单题超过 90 秒 |
| 猜题惩罚 | 无 — 始终作答，绝不空题 |

---

## 进度检查点

| 已用时间 | 目标进度 |
|----------|----------|
| 15 分钟 | 完成约 25% 题目 |
| 30 分钟 | 完成约 50% 题目 |
| 45 分钟 | 完成约 75% 题目 |
| 55 分钟 | 全部作答完毕 |

---

## 时间管理策略

1. **第一遍（40 分钟）：** 立即回答所有会的题
2. **标记难题：** 超过 90 秒标记并跳过
3. **第二遍（15 分钟）：** 处理被标记的题
4. **最终复查（5 分钟）：** 检查标记题

---

## 排除策略

1. 识别每个选项所指的确切 NVIDIA 术语
2. 排除混合了不相关概念的选项
3. 优先选择与工具**实际文档记载用途**匹配的选项

---

## 领域权重回顾

| 领域 | 权重 |
|------|------|
| 神经网络与 Transformer 基础 | ~15% |
| 扩散模型与生成模型 | ~15% |
| 视觉与多模态模型 | ~20% |
| 训练与评估 | ~20% |
| NVIDIA 软件栈 | ~15% |
| 安全与应用 | ~15% |

---

## 心理准备

- 注意 NOT、BEST、MOST、LEAST
- 相信你的准备
- 别反复纠结：第一直觉通常正确
- 保持冷静：60 分钟足够

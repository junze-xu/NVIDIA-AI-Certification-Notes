# 评估与对齐 — 速查表

## 多模态评估指标

| 指标 | 用例 | 方向 |
|------|------|------|
| BLEU | 翻译/字幕 | 越高越好 |
| ROUGE | 摘要 | 越高越好 |
| CIDEr | 图像字幕 | 越高越好 |
| CLIP Score | 文本到图像 | 越高越好 |
| FID | 图像生成质量 | 越低越好 |
| IS | 图像生成多样性 | 越高越好 |
| 困惑度 | 语言模型 | 越低越好 |

**考试规则：**
- 图像生成质量 → FID（越低越好）
- 图像多样性 → IS（越高越好）

---

## RLHF 三阶段

1. SFT → 2. 奖励模型 → 3. PPO

**考试陷阱：** 奖励模型必须在 RL 阶段之前训练。

## 幻觉

- 模型生成看似合理但事实上不正确的信息
- 最佳缓解：RAG（检索增强生成）
- Temperature 0.0 不能防止幻觉

# 真实世界多模态应用 — 速查表

## 应用案例

| 领域 | 应用 | 模态 |
|------|------|------|
| 医疗 | 医学影像分析 | 图像 + 文本报告 |
| 自动驾驶 | 感知 + 决策 | 摄像头 + 激光雷达 |
| 内容 | 图像/视频生成 | 文本 → 图像/视频 |
| 客服 | 多模态客服 | 文本 + 语音 + 图像 |
| 教育 | 智能辅导 | 文本 + 图像 + 语音 |

## RAG 多模态架构

查询（文本/图像）→ 多模态嵌入 → 向量搜索 → 检索多模态上下文 → VLM 生成

## 模型部署权衡

| 因素 | 考虑 |
|------|------|
| 延迟 | 实时应用需低延迟 |
| 吞吐 | 高并发需高吞吐 |
| 成本 | 大模型推理成本高 |
| 质量 | 大模型通常质量更高 |

---

## 部署最佳实践

- 使用 NIM 快速部署
- 动态批处理提高吞吐
- 模型量化减少内存
- 监控漂移和性能下降

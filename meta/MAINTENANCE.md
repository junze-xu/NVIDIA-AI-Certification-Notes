# 维护规则
**边界（方案 2）**：公开=笔记/速查卡/闪卡/术语对照/labs/每域样题 整套模拟卷+错题详解。**
**结构**：一考试一目录，目录内 `overview.md`（官方科目解读原文）· `notes/` · `cheatsheets/` · `flashcards/` · `questions/` · `labs/` · `mock/`；一考纲域一文件，文件头标「对应 DLI 单元 / 学习日」。
**overview.md 定位**：每门考试目录下的 overview.md 固定收录英伟达官方《科目解读》章节原文（考试介绍 + 参数 + 面向人群 + 推荐培训），作为该门考试的备考切入点；权重表不在 overview 内，仍在 README。
**拆分触发**：单门 >50 个 md 或需独立检索面 → 拆独立仓，主表留链接；仓名随时可改（GitHub 保留旧链接跳转）。
**发布前检查清单**：①无 *.pdf（.gitignore 兜底，仍要人眼看）②无参考仓正文搬移 ③首屏无「包过」字样 ④非官方声明在 H1 下方 ⑤关键数字与官方指南核对。
**提交纪律**：commit，按天推进；重大修正写进 CHANGELOG。

# NCP-AAI · 代理式 AI 中级认证

> NVIDIA-Certified Professional: Agentic AI — 验证设计、开发、部署和管理先进的代理式 AI 解决方案，侧重于多代理交互、分布式推理、可扩展性和道德保障。

## 考试定位

NCP-AAI 认证用于验证设计、开发、部署和管理先进的代理式 AI 解决方案，侧重于**多代理交互、分布式推理、可扩展性和道德保障**。

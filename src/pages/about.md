# 关于本站

## 这是什么

NVIDIA 认证备考站是一个非官方的个人学习笔记集合，覆盖 NCA 四门初级 + NCP 六门中级认证。

**本站与 NVIDIA 无关联**，使用 NVIDIA 商标仅为指代目的。

## 关注公众号「JunzeXuInfra」

每门考试的**完整速查表、知识卡片、模拟考试 PDF**，请关注公众号领取：

- 📱 **公众号**：JunzeXuInfra（回复考试代码，如 `NCA-AIIO`，领取免费样例）
- 🔵 **知识星球**：NVIDIA 认证备考圈（年费会员，独家资料 + 持续更新）
- 🌐 **博客站**：本仓库对应 GitHub Pages

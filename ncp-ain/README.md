# NCP-AIN · AI 网络中级认证

> NVIDIA-Certified Professional: AI Networking — 验证利用 NVIDIA 先进网络技术部署和配置环境的能力。

## 考试基本信息

| 项目 | 详情 |
|---|---|
| 考试编号 | NCP-AIN |
| 等级 | Professional（中级） |
| 前置建议 | NCA-AIIO / NCP-AII |
| 考试时长 | 120 分钟 |
| 题型 | 70–75 道选择题 |
| 考试费用 | 2880 元 |
| 证书有效期 | 2 年 |
| [官方考试页面](https://www.nvidia.cn/training/certification/ai-networking-professional/) | ↗ |

## 考试定位

NCP-AIN 认证验证利用 NVIDIA 先进的网络技术（Spectrum-X、InfiniBand、RoCE 等）**部署和配置环境**的能力。
